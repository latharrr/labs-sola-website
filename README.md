# Sola

A one-page demo site for Sola, a fictional bank for freelancers. Sola is not a real company and holds no money.

The layout follows mercury.com. The page is made of three moving layers:

- **Hero:** a living still. A Seedance 1.0 clip played forwards and back so the loop has no seam.
- **Scroll film:** one continuous push-in, made with Seedream keyframes and Seedance 1.0 clips on BytePlus ModelArk. Phones get a cropped, half-rate frame set.
- **How it works:** a payment-split diagram drawn in code (SVG).

It is a static site with no build step. Open `index.html` through any static server, for example `python3 -m http.server`.
